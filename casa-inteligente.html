⚙️ Configurações

Broker MQTT

Navegadores usam MQTT sobre WebSocket (EMQX: 8083 ws, 8084 wss). As portas 1883/8883 são TCP e não funcionam aqui. Você pode colar uma URL completa no campo Servidor.
Deve ser único: dois clientes com o mesmo ID derrubam um ao outro.

Autenticação

A senha nunca é salva no navegador.

Tópicos e subtópicos

Formato das mensagens
<prefixo>/<subtópico>/estado  (JSON, publicado pelo painel)
<prefixo>/<subtópico>/cmd     (comando: JSON parcial ou ON/OFF)

luzes  {"on":true,"dim":false}
ar     {"on":true,"temp":23}
ventilador {"on":true,"speed":2}
porta  {"locked":true}
cortinas {"open":50}
camera / alarme / tomadas  {"on":true}

Exemplo: casa/luzes/sala/cmd  →  ON
